# VietQR → Wise

A small SPA that decodes Vietnamese VietQR (NAPAS bank QR) codes via the device camera and helps you pay the recipient via Wise.

## Local development

```sh
npm install
npm run dev
```

## Deploy

Push to `main`. The GitHub Pages workflow at `.github/workflows/deploy.yml` builds the site and deploys it to <https://expelledboy.github.io/viet-qr-to-wise/>.
